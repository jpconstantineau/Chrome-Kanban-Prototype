# Chrome-Kanban-Prototype

Static Vanilla HTML/CSS/JS prototype for a Kanban board.

## Project structure

- `/public/index.html`
- `/public/styles.css`
- `/public/script.js`

No build tooling, dependencies, backend, accounts, or remote APIs are required.

## GitHub Pages setup (no GitHub Actions)

1. In the repository, open **Settings → Pages**.
2. Set **Build and deployment** source to **Deploy from a branch**.
3. Select the branch you want to publish and choose the `/public` folder.
4. Save.
